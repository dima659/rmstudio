# RMstudio — Telegram Mini App

Каталог, поиск вещи по фото или описанию, выбор размера, корзина, профиль с заявками и заказами.
Сервер на чистом Node.js (без зависимостей), данные в `data/db.json`.

## Запуск на Render
1. Создайте бота в @BotFather, скопируйте токен. Свой числовой ID узнайте у @userinfobot.
2. Залейте папку в GitHub-репозиторий.
3. Render → New → Blueprint (подхватит `render.yaml`) или New → Web Service: Build `npm install`, Start `npm start`.
4. В Environment задайте `BOT_TOKEN` и `ADMIN_CHAT_ID` (по желанию `CHANNEL_URL`, `REVIEWS_URL`, `SUPPORT_URL`).
5. После деплоя бот сам поставит вебхук и кнопку меню «Магазин» (адрес берётся из `RENDER_EXTERNAL_URL`).
6. Напишите боту `/start` и нажмите «Открыть RMstudio».

## Как работают заявки
Заявка или заказ приходит вам в Telegram (с фото, если есть). Ответить клиенту можно из чата с ботом:
- `/status 1042 searching|found|done|cancelled` меняет статус, клиент получает уведомление
- `/reply 1042 текст` отправляет клиенту сообщение

## Каталог
Редактируйте `catalog.json`: бренды для бегущей ленты, категории, товары (`image` — ссылка на фото, `price` — число или `null`).

## Локально
`npm start`, затем http://localhost:3000. Без `BOT_TOKEN` работает гостевой режим для проверки в браузере.

## Важно
На бесплатном тарифе Render сервис засыпает после 15 минут простоя, а файлы сбрасываются при перезапуске, поэтому заявки из `db.json` пропадут.
Для постоянного хранения подключите диск (платный тариф) с `DATA_DIR=/var/data` или перенесите хранилище в Render Postgres.
